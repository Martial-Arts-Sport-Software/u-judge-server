# U'Judge Server: release notes

## v1 Pilot (installer version 1.0.0)

Сборка для полевого испытания U'Judge v1 Pilot в изолированной Wi-Fi сети площадки. **Не production-релиз.** Номер `1.0.0`
требуется форматом DMG и MSI и обозначает пилотную сборку, а не production `1.0`.

### Состав

- Desktop площадки для Windows и macOS с managed PostgreSQL 18.6, HTTPS/WSS на порту `8443` и mDNS `_u-judge._tcp`.
- Импорт заявок `df-template-v1`, жеребьёвка по ФХР 2024, площадки, нумерация боёв и протоколы.
- Kerugi и Tanbon с таймером и ходом сетки, технические выступления, экран зрителей.
- История, XLSX/CSV, backup и восстановление.

### Ограничения пилота

- Один desktop peer на площадку и 5-7 судейских устройств; P2P между площадками не входит в пилот.
- Installers не подписаны (Windows signing и macOS notarization после пилота): macOS требует «Открыть» из контекстного
  меню при первом запуске, Windows SmartScreen - «Подробнее» → «Выполнить в любом случае».
- Приложение запускается от обычного пользователя Windows: PostgreSQL не работает с правами администратора.
- Backup не шифруется; храните каталог данных приложения на доверенном компьютере.
- После аварийного завершения таймер боя стоит на последнем сохранённом времени (до 5 секунд назад, ADR-010 §3); судейские
  нажатия позже этого времени сохраняются в журнале как «вне времени боя».
- Нормативные векторы технических дисциплин и чтение tie-break ждут заключения эксперта-судьи.
- Английские PDF правил не являются переводом и не используются как источник.

Статусы требований и открытые пункты - в [roadmap](ROADMAP.md).
